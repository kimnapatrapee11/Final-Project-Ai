# คำนวณค่ารถไฟฟ้า BTS / MRT

เว็บไซต์คำนวณค่าโดยสารรถไฟฟ้า BTS (สายสุขุมวิท/สีลม ช่วงหลัก) และ MRT สายสีน้ำเงิน
เป็น HTML + JavaScript ล้วน ไม่ต้องติดตั้งอะไร เปิด `index.html` ได้ทันที

## ความสามารถ

- เลือกสถานีต้นทางและปลายทาง คำนวณจำนวนสถานีและค่าโดยสาร
- เพิ่มได้หลายช่วง เช่น BTS ต่อ MRT ระบบจะรวมราคาให้
- ราคาสำหรับบุคคลทั่วไป ผู้สูงอายุ (ลด 50%) และกลุ่มที่ MRT สายสีน้ำเงินให้ฟรี
- ประมาณค่าใช้จ่ายต่อเดือนจากจำนวนเที่ยวและวันเดินทาง

## เผยแพร่บน GitHub Pages

1. สร้างรีโพซิทอรีใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ Settings → Pages
3. ที่ Source เลือก Deploy from a branch แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
4. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโพ>/`

## แก้ไขราคา

แก้ที่ตารางต้นไฟล์ `fares.js`

- `MRT_BLUE_FARES` ราคาตามจำนวนสถานี ตามข้อบังคับ รฟม. มีผล 3 ก.ค. 2569 (17-44 บาท)
- `BTS_FARES` ราคาตามจำนวนสถานี ช่วงราคา 17-47 บาท ตามประกาศ BTS ปี 2566
  **ยังไม่ได้ตรวจรายจำนวนสถานีกับตารางทางการ** ตั้ง `BTS_FARES_VERIFIED = true` หลังตรวจแล้ว
  เพื่อซ่อนข้อความเตือนในหน้าเว็บ

BTS นับ "เสนาร่วม" ซึ่งเป็นสถานีที่ยังไม่ได้สร้างเป็น 1 สถานีในการคิดค่าโดยสารมาตั้งแต่เปิดบริการ
โค้ดจึงนับสถานีนี้ในการคำนวณแต่ไม่แสดงในรายการ

## ขอบเขตที่ยังไม่รวม

ส่วนต่อขยาย BTS (หมอชิต–คูคต, อ่อนนุช–เคหะฯ, สะพานตากสิน–บางหว้า) สายสีม่วง สายสีเหลือง สายสีชมพู
สายสีแดง และ Airport Rail Link
